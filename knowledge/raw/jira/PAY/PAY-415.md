# PAY-415: 409 returned for a retried request with re-ordered JSON keys

**Type:** Bug · **Status:** In Progress · **Priority:** High

## Description
The mobile SDK serializes the same body with a different key order on retry. We compare raw bodies, so the retry gets `409 Conflict`.

## Comments
- **omar.levi (2026-10-02):** Fix: compare a canonical JSON hash instead of the raw body.
