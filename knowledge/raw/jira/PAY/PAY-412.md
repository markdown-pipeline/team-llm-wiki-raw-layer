# PAY-412: Add idempotency keys to POST /payments

**Type:** Story · **Status:** Done · **Fix version:** 2026.10

## Description
Clients retrying `POST /payments` after a timeout can create duplicate charges. Implement idempotency keys as decided in ADR 014.

## Acceptance criteria
- `Idempotency-Key` header accepted (UUID v4).
- Same key + same body within 24 h → return the original response.
- Same key + different body → `409 Conflict`.

## Comments
- **omar.levi (2026-09-21):** Keys are stored in Redis with a 24 h TTL. A Postgres fallback was rejected (latency).
- **jane.doe (2026-09-29):** Verified in staging. Closing.
